# AFLY DDI backup

Immutable DDI snapshots for AFLY. The Android app checks locked hashes before use.

Source: https://github.com/doronz88/DeveloperDiskImage
Upstream snapshot: `6eae353ae694bda1c421d4a3eee5459ae59c99a1`

DDI images originate from Apple; the upstream software license is not a separate license grant for Apple's images. These are unmodified source payloads. Apple signing and device mounting remain required.

No APK, application configuration, pairing record, device identifier, token or signing key is included.
